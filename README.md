# Group 9 Midterm Project – Sales Data Analysis

## Project Overview
This project demonstrates a sales data workflow using Microsoft Azure and Power BI. The goal is to store sales data, process it, analyze sales information, and present the results in a dashboard.

## Technologies Used
- **Azure Blob Storage:** Stores the original and processed sales data.
- **Azure Data Factory:** Copies data between Blob Storage containers.
- **Azure SQL Database:** Provides a database for storing and querying sales data.
- **Power BI:** Visualizes sales performance through charts and KPI cards.

## Project Workflow
1. Upload the sales dataset to Azure Blob Storage.
2. Use Azure Data Factory to copy the dataset to the processed-data container.
3. Use SQL queries to analyze sales by month and country.
4. Use Power BI to display sales trends, country performance, product lines, and order information.


## Security and Configuration
Blob Storage containers are configured for private access, with anonymous access disabled. Azure resources and their settings are documented in the project report.
